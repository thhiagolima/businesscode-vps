Editor de Funil — Abordagem Visual

Qual estilo de editor para criar sequências automatizadas?

A

Vue Flow (Fluxograma Conectado)

Biblioteca @vue-flow/core — nós arrastáveis conectados por linhas. Cada nó é um bloco (mensagem, delay, condição). Conexões definem o caminho. Padrão da indústria (n8n, Botpress, ManyChat).

Pros

  • Visual intuitivo tipo fluxograma
  • Suporta ramificações (condições com 2+ saídas)
  • Biblioteca madura (10k+ stars)
  • Zoom, pan, minimap built-in

Cons

  • +80KB bundle size
  • Curva de aprendizado para customizar nós
  • Mais complexo de implementar
B

Lista Sequencial com Drag-and-Drop

Lista vertical de blocos arrastáveis com vuedraggable. Mais simples — cada bloco é um card que pode ser reordenado. Condições ficam como "if/else" inline. Sem linhas de conexão.
